## 🚀 Overview

E-Midas Hospital AI CRM is a complete healthcare management platform that helps hospitals and clinics manage:

- 👥 Patients
- 👨‍⚕️ Doctors
- 🏥 Clinics
- 📅 Appointments
- 📧 Email Communications
- 📊 Analytics & Reports
- 🤖 AI Chatbot Assistance

The platform uses Google Gemini AI to provide intelligent patient interaction and lead generation.

# ⚙️ Installation

## Clone Repository

```bash
https://github.com/Chethankumar2452/E-Midas-Chatbot-Full-Project.git

cd E-Midas-Chatbot-Full-Project
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create:

```bash
.env.local
```

Add:

```env
MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

GEMINI_API_KEY=your_gemini_api_key

EMAIL_USER=your_email@gmail.com

EMAIL_PASS=your_app_password

NEXT_PUBLIC_API_URL=http://localhost:3000
```

# ▶️ Running the Project
